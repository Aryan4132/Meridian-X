# Finance Skill

Market and net-worth sentinel. Loaded lazily on stock, portfolio, or
price prompts.

## Tools

| Tool | Tier | Purpose |
| ---- | ---- | ------- |
| `analyze_stock_sentiment` | 0 | Sentiment summary for a ticker. |
| `get_market_watchlist` | 0 | Show tracked market watchlist. |
| `get_networth_summary` | 1 | Assets-vs-liabilities snapshot. |
| `add_watched_product` | 1 | Track a product for price drops. |
